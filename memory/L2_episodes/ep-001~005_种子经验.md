# L2 经验记录（KSTAR）

> 每条都是结构化 S→T→A→R 经验，是从 L1 原始信息到「知识」的转化层。
> 命名 `ep-XXX_主题.md`，按时间/主题归类。

## ep-001 C1 翻译项目（translation-workflow 的种子经验）

- **S（Situation）**：C1 要求完成一个翻译项目，含术语表、README、AAR、拿来说明四件套。
- **T（Task）**：产出一致、可复用的翻译成果，不能凭感觉乱译。
- **A（Action）**：先建术语表（glossary.md）统一专有名词 → 翻译正文 → 写 README 说明 → 最后做 AAR 复盘。
- **R（Result）**：四件套齐全；术语表让全文译名一致，是最大价值点。
- **提炼信号**：① 「先术语表后正文」是翻译的通用步骤；② 「拿来说明 + AAR」几乎是每个挑战的固定收尾。

## ep-002 C2 AI4Math 论文（paper-writing 的种子经验）

- **S**：C2 要产出一篇 7 页 AI4Math 论文，14 篇一手文献全需核验。
- **T**：论文要能编译（PDF），引用要真实可追溯，不能编。
- **A**：文献检索记录 → 每篇核验（文献核验表.md）→ 写 references.bib → 写正文 → tectonic 编译成 paper.pdf → AAR。
- **R**：paper.pdf 编译通过；14 篇引用全部一手核验；提交 sub-20260927072336-140c8bc2，pendingReview。
- **提炼信号**：① 引用必须逐条核验「原句是否真在来源里」；② 编译是论文交付的硬门槛，先保证能编译再谈润色。

## ep-003 C9 MetaCog-Bench 调试 KeyError（debug-workflow 的种子经验）

- **S**：C9 benchmark 的 cli.py 读 `accuracy`，但 scorer.py 返回的是 `acc`，运行直接 KeyError。
- **T**：让 pipeline 跑通，且不能靠「猜」修。
- **A**：先稳定复现报错 → 定位是「字段名不一致」这一个根因 → 对齐键名（统一成 accuracy）→ 跑通后加 `--seed 0` 保证可复现 → 补 reliability.py 做多 seed 验证。
- **R**：pipeline 跑通；合成画像 ECE/AUROC/弃答增益都能区分校准质量；reliability 证据补齐（ECE std ≤0.09）。
- **ΔR 教训**：报错别急着改，先「复现 + 定位唯一根因」，否则会打地鼠。这条直接催生了 debug-workflow Skill。

## ep-004 EduSeed 提交链路踩坑（version-management / 提交规范的种子经验）

- **S**：C4A/C4B 等提交时，总在纠结「目录名还是文件名才算命中 required_deliverables」。
- **T**：搞清楚 `*关键词*` 到底怎么匹配，别再误判落库失败原因。
- **A**：用 C4A 实证——`*skill-evaluator*` 只出现在目录名、无同名文件，仍成功落库 sub-20261005111313。→ 结论：`*关键词*` 同时命中目录名和文件名。
- **R**：规则固化进共享记忆；后续 C6/C7/C8 提交少走了弯路。
- **提炼信号**：这条「实证排障」的经验值得存成共享事实，也说明「用证据说话」是排障 Skill 的核心。

## ep-005 C10 runtime payload bug（本次 debug-workflow 的再次验证）

- **S**：C10 查题脚本 `run-c10-getchallenge.js` 报 `INPUT_MISSING: challengeId 必填`。
- **T**：让 get-challenge / get-challenge-content 正确拿到 challengeId。
- **A**：读 runtime.js 定位 `parseRuntimeArgs` 根因——它只把「第一个 JSON 参数」当 payload 根，之前的嵌套 `{op, payload}` 导致 `payload.challengeId === undefined` → 改成平铺 `{challengeId, workdir}` → 成功。
- **R**：两个脚本修复后都成功；workdir 用正斜杠避开 `\U` Unicode 转义坑。
- **ΔR 教训**：debug-workflow Skill 的「读源码定位根因」步骤再次命中——和 ep-003 是同一类问题（字段/结构不匹配），Skill 有效，继续用。
