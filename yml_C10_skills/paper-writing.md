# paper-writing

## What
一条「文献可追溯 + 能编译交付」的写作流程。价值点在于：引用不是「网上抄来」，而是「每条都能定位到原句」。

## When to Use
- 要写论文、技术报告、综述，且引用是评分/审稿重点。
- 交付物必须是可编译的 PDF（或等价最终格式）。

## Input
- 主题 + 目标篇幅 + 引用数量要求。
- 可用的文献库/检索渠道。

## Steps
1. 文献检索记录（`文献检索记录.md`）：查了什么库、用了什么词、命中哪些。
2. 每篇建核验表（`文献核验表.md`）：标题/DOI/作者/「原句是否真在来源里」逐条打勾。
3. 写 `references.bib`，只收核验通过的一手文献。
4. 写正文，主张—证据—推理对齐。
5. 编译成 PDF（保证能编译，再谈润色）。
6. 写 AAR。

## Tools
- LLM（写作/推理）、编译工具（tectonic / pandoc）、write_file。

## Output
- 正文 + `references.bib` + `文献核验表.md` + 可编译 PDF + AAR。

## 使用与迭代记录
- 使用次数：2（C2 AI4Math 论文；C2A 提案的文献背景部分）。
- 迭代 v1→v2：C2 前几稿先写正文再补引用，导致「引用对不上主张」；改成「先核验后写正文」，14 条引用全过。
- 淘汰标记：无。
