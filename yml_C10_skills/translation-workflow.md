# translation-workflow

## What
一个把「翻译材料」变成「交付物四件套」的可执行流程。核心价值不是逐句翻译，而是先用术语表锁死专有名词，让全文译名一致。

## When to Use
- 有整段/整篇材料要翻译，且需要正式交付（课程挑战、公开文档、技术手册）。
- 材料里有大量专有名词、缩写、概念术语，翻译容易前后不一。

## Input
- 原文（文本/文档，语言 A→B）。
- 交付要求（是否要 README、是否要 AAR、是否要拿来说明）。

## Steps
1. 通读原文，抽出所有专有名词/缩写/概念，建 `glossary.md`（术语：原文→译名→是否自定）。
2. 按术语表翻译正文，遇到新词回写术语表。
3. 写 `README.md`：说明翻译范围、术语表位置、如何复用。
4. 写 `AAR复盘.md`：卡点、误译案例、改进方向。
5. （可选）写 `拿来说明.md`：哪些是直接翻译、哪些参考、哪些自创。

## Tools
- LLM（翻译/术语抽取）、write_file（落盘）。

## Output
- `glossary.md` + 译文 + `README.md` + `AAR复盘.md`（+ `拿来说明.md`）。

## 使用与迭代记录
- 使用次数：2（C1 翻译项目；C2 论文中译英术语整理）。
- 迭代 v1→v2：C2 时把「先翻译后补术语表」改成「先术语表后翻译」，译名一致率从「偶发不一致」到「零不一致」。
- 淘汰标记：无。
