# aar-generator

## What
一条「把经历变成可复用教训」的复盘流程，是 KSTAR 循环里「R → 下次更好」的那一环。核心价值：用 ΔR=R̂−R 逼出「我哪里判断错了」。

## When to Use
- 每次挑战/项目收尾（C1–C9 都用）。
- 想从一次失败/卡点里提炼出可复用的改进。

## Input
- 真实经历：目标、过程、卡点、结果（可有 AI 日志佐证）。

## Steps
1. 写经历（S/T/A）。
2. 写预测结果 R̂（我当时以为会怎样）。
3. 写实际结果 R，算偏差 ΔR=R̂−R。
4. 归因：ΔR 大/方向一致，说明哪类判断系统性问题。
5. 提炼教训 + 可执行改进动作（落到 Skill 更新或新 Skill 候选）。
6. 落盘为 AAR + 把教训写回 L2 经验。

## Tools
- LLM（复盘）、write_file。

## Output
- `yml_CX_AAR复盘.md` + L2 经验条目 + 可能的 Skill 迭代。

## 使用与迭代记录
- 使用次数：≥8（C1–C9 每项 + C10 自身）。
- 迭代 v1→v2：v1 只写「做了什么 + 结果」；v2 强制写 R̂ vs R 的 ΔR，C9 的 KeyError 教训、C10 的 runtime bug 教训都靠它沉淀。
- 迭代 v2→v3：增加「ΔR 是否方向一致」判断，用于区分偶发失误 vs 系统性误区。
- 淘汰标记：无。
